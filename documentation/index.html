LoRaVSN: A LoRa ML-Assisted Image Transmission Framework for IoT Computer Vision Applications

About

LoRaVSN is a modular image transmission framework designed to extend computer vision capabilities to environments where Wi-Fi or high-bandwidth Internet access is limited, unreliable, or unavailable. While many edge computer vision systems depend on costly hardware or stable network infrastructure to transmit images or video to a central processing unit, this assumption does not always hold in outdoor, distributed, or infrastructure-limited deployments. To address this challenge, LoRaVSN uses LoRa, a low-power and long-range communication technology, to transmit reduced image data from resource-constrained edge devices to a gateway.

Although the framework is validated through the PARKS parking monitoring use case, its broader purpose is to make edge computer vision more accessible and deployable in off-grid, low-connectivity, and resource-constrained environments.

Hardware Requirements

  • (1) Raspberry Pi 5 (8GB)
  • (1) Generic Espressif ESP-WROOM-32
  • (2) REYAX RYLR998 LoRa Modules

NOTE: The role played by the Raspberry Pi 5 in LoRaVSN can be replaced by any capable enough computer with internet connection and a USB-to-UART bridge adapter connected to the REYAX RYLR998 LoRa Module.
