LoRaVSN Application Layer CLI

The Application Layer CLI acts as a lightweight client for a running LoRaVSN system. It connects to the Web API, retrieves image data, and optionally saves the received images locally for inspection or testing.

This tool is a wrapper for the Web API endpoint, and designed to facilitate accessing image data generated by the LoRaVSN Gateway.

Prerequisites

Before running the tool, ensure you have the required Python libraries installed:

pip install requests

Usage

The tool requires the LoRaVSN Web API to be running and accessible at the configured BASE_URL.

By default, received images are stored inside the received_images/ directory. The directory is automatically created if it does not already exist.

Command Line Flags

Argument Default Description
-p, --ping False Sends a request to the API root endpoint (/) to verify connectivity.
-d, --listen False Continuously listens for incoming image data from the API.
-s, --save False Continuously retrieves and saves received images into the output directory.
--save-one False Retrieves and saves a single image, then exits.

Example Commands

Ping the Web API:
python loravision/end_user/client/application.py --ping
Receive and save a single image:
python loravision/end_user/client/application.py --save-one
