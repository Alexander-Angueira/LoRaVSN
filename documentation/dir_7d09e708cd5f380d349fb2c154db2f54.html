Detailed Description

Remote Node — Image Segmentation

ROI (Region of Interest) extraction from grayscale images using COCO-formatted bounding boxes, designed for the ESP32 Remote Node.

Functions

ParseBbox

SegmentationStatus ParseBbox(const char* bbox_str, int* x, int* y, int* w,
int* h);

Parses a COCO-formatted bounding box string ("x,y,bbox_width,bbox_height") into four integer values. Values must be comma-separated with no spaces. Width and height must be greater than zero, and x/y must be non-negative.

ExtractRoi

SegmentationStatus ExtractRoi(const uint8_t* image, int image_width,
int image_height, const char* bbox_str,
uint8_t* output);

Extracts a rectangular ROI from a row-major grayscale image and writes it into a caller-provided output buffer. The output buffer must be pre-allocated with at least bbox_width * bbox_height bytes.

SegmentationStatus

enum SegmentationStatus {
kOk = 0,
kNullPointer,
kInvalidBboxFormat,
kInvalidDimensions,
kOutOfBounds,
};

Usage

#include "segmentation.h"
const int kImageWidth = 320;
const int kImageHeight = 240;
uint8_t image[kImageWidth * kImageHeight];
// Output buffer for a 100x80 ROI.
uint8_t roi[100 * 80];
SegmentationStatus status = ExtractRoi(image, kImageWidth, kImageHeight,
"50,30,100,80", roi);
if (status != kOk) {
// Handle error based on status code.
}

Memory

Both functions operate entirely on caller-provided buffers. No heap allocation is performed. The ROI is copied row-by-row from the source image into the output buffer using memcpy.

Target platform: Denky32 (ESP32-WROOM-32), 320 KB internal SRAM.

Limitations

  • Only supports 8-bit grayscale images (1 byte per pixel).
  • Bounding box values must be integers (no floats).
  • The entire ROI must fit within the image; no partial/clipped extraction.
  • Spaces between values in the bbox string are rejected.
