Detailed Description

Thin wrapper around the REYAX RYLR998 module exposed over UART.

A ``LoRaRadio`` is constructed with an open serial-like object so
that the same code path is used in production (``serial.Serial``)
and in unit tests (a fake serial object).

Args:
    serial (Serial):          Initialized object for serial
                              communication with LoRa module.
    buffer (bytes):           Place to store received serial data.

Configure the LoRa module.

The order of commands matches the Remote Node so the two sides
of the link can be brought up in the same way.

Args:
    address:          The LoRa module's address inside the LoRa
                      network.
    network_id:       The LoRa network id used for identifying
                      the LoRa network.
    spreading_factor: Sets the module spreading factor.
    bandwidth:        Sets the module bandwidth.
    coding_rate:      Sets the module coding rate.
    preamble_code:    Sets the module preamble code.

Returns:
    ``True`` if every AT command came back with ``+OK``,
    ``False`` otherwise.

Raises:
    ValueError: If `address` or `network_id` are outside the
        range specified by the REYAX RYLR998 LoRa module.

Sends ``message`` to every node in the network.

This uses the RYLR998 LoRa Module reserved broadcast address.

Args:
    message: Object with the data to be sent.

Returns:
    ``True`` is returned only when transmission is accepted by
    the LoRa module, ``False`` otherwise.

Raises:
    ValueError: If recipient LoRa address is out of the range
        specified by the REYAX RYLR998 LoRa module, or if the
        message length is less than 0, or greater than
        `MAX_PAYLOAD_LENGTH`.
