Detailed Description

Holds the contents of a message to be sent to the REYAX RYLR998 LoRa module.

This class encapsulates the contents of a message as defined by the LoRaVSN project custom messaging format, and offers methods to easily access and set the contents of the message to be sent to the LoRa network.

For more information regarding the LoRaVSN messaging format, see: docs/loravsn_messages.md
