LoRaVSN Management Layer CLI

The Management Layer CLI is a tool for configuring and managing a running LoRaVSN system through its Web API. It allows the end user to inspect current settings, restore default configurations, and update some transmission parameters, module parameters (to be implemented), and some compression parameters without restarting the system.

Prerequisites

Before running the tool, ensure you have the required Python libraries installed:

pip install requests

Usage

The tool requires the LoRaVSN Web API to be running and accessible at the configured BASE_URL.

Implemented Command Line Flags

NOTE: Some arguments available at the CLI loravision/end_user/client/management.py -h will NOT alter parameters in the LoRaVSN system. It will update those configurations in the Web API, but these will not take effect, since they are not implemented. All the flags in the table below are implemented, and behave as documented.

Argument Default Description
-p, --ping False Sends a request to the API root endpoint to verify connectivity.
-i, --info None Retrieves the current configuration of a specific category: transmission, module, compression.
--defaults None Restores default parameters for the specified configuration category: transmission, module, compression.
--start-transmission None Enables data transmission between Gateway and Remote Node.
--stop-transmission None Disables data transmission between Gateway and Remote Node.
--packet-size None Sets the maximum bytes allowed per transmitted packet.
--start-throughput-test None Starts throughput testing mode.
--stop-throughput-test None Stops throughput testing mode.
--start-roi-extraction None Enables ROI extraction.
--stop-roi-extraction None Disables ROI extraction.
--reset-rois None Clears stored ROIs from the Remote Node.
--keep-rois None Preserves existing ROIs on the Remote Node.

Example Commands

Ping the Web API:
python loravision/end_user/client/application.py --ping
See current settings:
python loravision/end_user/client/management.py --info compression
python loravision/end_user/client/management.py --info transmission
python loravision/end_user/client/management.py --info module
Restore default settings:
python loravision/end_user/client/management.py --defaults transmission
python loravision/end_user/client/management.py --defaults module
python loravision/end_user/client/management.py --defaults compression
Start or Stop Transmissions:
python loravision/end_user/client/management.py --start-transmission
python loravision/end_user/client/management.py --stop-transmission
Reset ROIs stored in Remote Nodes
python loravision/end_user/client/management.py --reset-rois
