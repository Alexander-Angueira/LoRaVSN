ESP32 Input Simulation Tool

The Input Simulation Tool acts as a "virtual camera sensor" for the LoRaVSN remote node. It reads images from the local dataset, converts them into raw byte arrays, and transmits them over a Serial/UART connection to the ESP32 for local processing.

This tool is designed to facilitate the testing of image segmentation and compression algorithms without requiring a physical camera module.

Prerequisites

Before running the tool, ensure you have the required Python libraries installed: pip install pyserial Pillow

Usage

The tool requires the ESP32 to be connected and listening for the REQ_IMG handshake over the serial port. Ensure the Serial Monitor in PlatformIO/VS Code is closed before running the script to prevent port conflicts.

python tools/simulate_input.py --image <path_to_image> [options]

Configuration Options

Argument Type Default Description
--image string Required The relative or absolute path to the target image file.
--format string grayscale The format of the transmitted byte array.
Choices: grayscale, rgb, jpeg.
--port string COM4 The Serial/COM port the ESP32 is connected to.
--baud int 115200 The baud rate. Must match the monitor_speed in platformio.ini.

Example Command

To send a grayscale crop from the testing dataset: python tools/simulate_input.py --image dataset/crops/Scene_0/image_crop_0.jpg --format grayscale --port COM4
