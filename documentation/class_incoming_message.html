Detailed Description

Holds the contents of a message received through the REYAX RYLR998 LoRa module.

This class encapsulates the contents of a received message as defined by the LoRaVSN project custom messaging format, and offers methods to easily access the contents of the message received from the LoRa network.

For more information regarding the LoRaVSN messaging format, see: docs/loravsn_messages.md
