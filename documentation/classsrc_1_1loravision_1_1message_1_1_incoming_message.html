Detailed Description

LoRaVSN Incoming Message.

Args:
    address (int):        Message sender LoRa address.
    type (str):           Message category.
    packet_id (int):      Sequence number used to reassemble
                          multi-packet payloads.
    payload (bytes):      ASCII encoded bytes.
    rssi (int):           Received Signal Strength Indicator.
    snr (int):            Signal-to-Noise Ratio.

Attributes:
    message_length (int): Message length (including length of the
                          LoRaVSN header).
    payload_length (int): Payload length (excluding length of the
                          LoRaVSN header).
