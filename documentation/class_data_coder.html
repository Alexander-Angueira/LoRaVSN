Detailed Description

Provides tools for compressing and encoding image data. Implements the Coding Layer.

This class offers the tools necessary for encoding and compressing image data. The class implements methods to allow performing Region of Interest (ROI) extraction, and RLE or JPEG compression in grayscale image buffers.

uint8_t * DataCoder::AllocateAlignedImageBuffer ( size_t size)

Allocates 16-byte aligned memory for image processing.

Wraps the ESP_NEW_JPEG library's built-in aligned allocator. This is required because the hardware-accelerated SIMD encoder will crash if the memory addresses do not perfectly align to 16-byte boundaries.

Parameters
sizeThe amount of memory to allocate in bytes.
Returns
Pointer to the newly allocated 16-byte aligned buffer, or nullptr if the ESP32 is out of memory.

Compresses an 8-bit grayscale image into JPEG format.

Utilizes the ESP_NEW_JPEG hardware-optimized library (One-Shot encoder) to compress the image. It dynamically allocates a 16-byte aligned output buffer. The caller is responsible for freeing this output buffer using FreeJPEGBuffer() to prevent memory leaks.

Parameters
inputPointer to the raw 8-bit grayscale image buffer (must be 16-byte aligned).
widthThe width of the image in pixels.
heightThe height of the image in pixels.
outputDouble pointer used to return the dynamically allocated compressed buffer.
out_lenPointer to a size_t variable where the final compressed byte count will be stored.
Returns
true if the JPEG compression was successful, false otherwise.

Compresses an image buffer using Run-Length Encoding (RLE).

This method processes the raw image data and overwrites the input buffer with the compressed result in-place, requiring no additional heap memory.

Parameters

lengthThe total size of the uncompressed image buffer in bytes.
Returns
The new, compressed size of the buffer in bytes. Returns 0 if the input length is 0, -1 if the compressed buffer is greater than the input buffer.

SegmentationStatus DataCoder::ExtractRoi ( const uint8_t * image,
int image_width,
int image_height,
const char * bbox_str,
uint8_t * output )

Extracts a region of interest (ROI) from a grayscale image.

Receives a row-major grayscale image as a uint8_t array, the image dimensions, a COCO-formatted bounding box string, and a pointer to an output buffer. Copies the ROI defined by the bounding box into the output buffer. The caller must pre-allocate the output buffer with at least bbox_width * bbox_height bytes.

Parameters
imagePointer to the source grayscale image byte array.
image_widthWidth of the source image in pixels.
image_heightHeight of the source image in pixels.
bbox_strCOCO-formatted bounding box string ("x,y,bbox_width,bbox_height").
outputPointer to the output buffer for the extracted ROI.
Returns
kOk on success, or an error status code.

Parses a COCO-formatted bounding box string.

Receives a null-terminated string with the format "x, y, bbox_width, bbox_height" and parses it into four integer values. Input values must be comma-separated with no spaces. width and height must be greater than zero, and x and y must be non-negative.

Parameters

Returns
kOk on success, or an error status code.
