Detailed Description

Interface for serial communication with REYAX RYLR998 LoRa module. Implements the LoRa Communication Layer.

This class offers a wrapper for AT Commands used for serial communication with REYAX RYLR998 LoRa module. The class handles packaging long messages for transmission, and parsing received messages into the Message object.

For more information regarding AT Commands, see: docs/reyax_lora_at_command_guide.pdf

Gets a string with the specified packet from data.

This method will return the slice of data corresponding to the specified packet_id. This slice has at most a packet_size length, if the slice is smaller than packet_size, the packet size will be truncated to that of the slice. The slice start is calculated as packet_id * packet_size.

◆ SendMessage()

bool LoRaRadio::SendMessage ( const OutgoingMessage & message)

Sends a message to a peer through the LoRa network.

Receives a OutgoingMessage object, and sends its contents through the LoRa network. The method will return false if the Message length is greater than kMaxPayloadLength.

The method guarantees that a message is received by the REYAX RYLR998 LoRa module, not that it has been received by the LoRa peer.

Parameters
messageOutgoingMessage object with the contents of the message to be sent to a peer through the LoRa network.
Returns
true if the message was sent to the LoRa module successfully, false otherwise.
