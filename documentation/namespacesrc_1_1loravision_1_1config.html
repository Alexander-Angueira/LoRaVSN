Detailed Description

Default configuration for the Raspberry Pi 5 LoRaVSN Gateway.

These values mirror the constants defined in `gateway/include/config.h` and
`remote_node/include/config.h` so the Gateway and the Remote Nodes stay in
sync. Override them at runtime when constructing a `LoRaRadio` if a different
deployment requires it.
